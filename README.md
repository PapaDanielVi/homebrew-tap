# homebrew-tap

A collection of Homebrew casks for my CLI tools.

## Available Casks

| Cask | Description |
|------|-------------|
| [jamshid](https://github.com/PapaDanielVi/jamshid) | CLI tool for managing multiple Claude Code profiles |
| [neo4j-exporter](https://github.com/PapaDanielVi/neo4j-exporter) | Prometheus exporter for Neo4j graph databases |
| [secret-shift](https://github.com/PapaDanielVi/secret-shift) | CLI tool for migrating and syncing secrets between providers |

## Installation

```bash
brew tap PapaDanielVi/homebrew-tap
brew install <cask-name>
```
